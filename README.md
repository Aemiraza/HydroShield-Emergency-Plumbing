# HydroShield 24/7 Emergency Plumbing

A high-trust, high-conversion local emergency plumbing landing page built specifically for the Dallas & DFW metroplex.

## 🚀 Live Demo & Local Preview

The landing page is self-contained with zero external framework dependencies (Vanilla HTML5, CSS3, and modern JavaScript).

To start the local server:
```bash
node server.js
```
Then visit: **[http://localhost:3000/](http://localhost:3000/)**

---

## 🎨 Design & Layout Style

- **Trustworthy Industrial Color Palette**:
  - Deep Navy Blue (`#0F172A`, `#070D1E`) represents dependability, corporate scale, and authority.
  - Vibrant Safety Emergency Red (`#EF4444`, `#DC2626`) with pulsing alerts for immediate high-contrast emergency CTAs.
  - Safety Amber / Gold (`#F59E0B`) for 5-star ratings, BBB accreditation, and warranty badges.
  - Clean Crisp White Cards (`#FFFFFF`) with subtle slate borders and drop shadows.
- **Bold, Easy-to-Read Typography**:
  - High-contrast Plus Jakarta Sans with heavy tabular figures for phone numbers and arrival time counters.
  - Fully accessible WCAG AAA compliant color contrasts.
- **Mobile-First UX & High Touch-Target Visibility**:
  - Minimum 56px touch targets for rapid one-thumb calling.
  - Persistent sticky mobile bottom bar with instant tap-to-call `(555) 849-2900` and rapid dispatch booking.
